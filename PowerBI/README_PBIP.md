# Paper 3 dashboard (Power BI Project, one page)

Generated by script on Linux and checked offline only (Microsoft JSON schemas, TOM TMDL load, M parser, lint). **The current version has not been tested in Power BI Desktop yet.**

## Open
1. Project folder: `C:\Users\sanga\Desktop\Pranav Paper3_Final\PowerBI\` (keep `Paper3_Dashboard.pbip` and the `.Report` and `.SemanticModel` folders side by side).
2. The data source is the parameter `CsvPath` = `C:\Users\sanga\Desktop\Pranav Paper3_Final\output\merged_all_11participants_8min.csv`. To move the CSV, change it in Home > Transform data (arrow) > Edit parameters > `CsvPath`.
3. Double-click `Paper3_Dashboard.pbip` (a recent Power BI Desktop; on older builds first turn on File > Options > Preview features: "Power BI Project (.pbip) save option", "Store semantic model using TMDL format", "Store reports using enhanced metadata format (PBIR)", then restart).
4. Home > Refresh. The project carries no data cache, so visuals stay blank until the first refresh succeeds.
5. File > Save (or Save as > "Power BI files (*.pbix)").

Parameter `MaxElapsedMin` (default 8) keeps the first 8 min of each phase; only Indoor of P8 and P17 is longer (89 rows dropped).
Generator and checks: `_build_helpers/` (on the build machine only, not delivered).
