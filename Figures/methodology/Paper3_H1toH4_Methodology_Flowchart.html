Why report both raw and FDR-adjusted p-values? Every test first produces a raw p-value. FDR then adjusts those raw p-values to account for testing many measures and hypotheses. Because FDR-adjusted p-values are always at least as large as raw p-values, if p_FDR < 0.05 then p < 0.05 too. The notebook reports both, and a result is flagged significant only when both are below 0.05.
Diagnostic standards LMM residuals (H1/H3/H4): Shapiro-Wilk test on residuals, caution if p < 0.01; |cor(abs(residual), fitted)| > 0.20 flags residual-spread caution (informal screen, not Breusch-Pagan). H2 correlation: Spearman rank correlation computed only when n ≥ 8 phase-mean pairs; scatterplots inspected for monotonicity.
